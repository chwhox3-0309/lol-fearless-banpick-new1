# 스킬 이펙트 점검 기록

## 확인 범위
- 인게임 화면은 로컬 `file://` 탭에 대한 브라우저 접근이 차단되어 실제 모바일 화면에서 시각 확인하지 못했다.
- 아래 내용은 그리기 코드와 사용 이미지 확인, 기존 렌더링 테스트에 근거한 점검이며 실제 화면 품질 합격 판정이 아니다.

## 확인 결과
| 스킬·효과 | 현재 표현 | 확인 사항 및 후속 시각 점검 |
|---|---|---|
| 기본 탄환·로켓·드론탄 | 청록색 발광과 밝은 장갑, 주황색 포인트 | 탄막과 겹칠 때 발사체의 크기 및 대비 확인 필요 |
| 추가 주무기·보조무기 21종 | 공통 투사체 함수에서 유도·관통·중포 등으로 분기 | 같은 분기를 쓰는 스킬 간 외형이 비슷해 보일 수 있어 유형별 플레이 확인 필요 |
| 추적·히든 유도탄 | 밝은 동체, 궤적과 피격 효과; 히든은 보라색 강조 | 다수 발사 시 궤적이 적 탄환을 가리는지 확인 필요 |
| 화염 방사기 | 별도 캔버스의 주황·노랑 화염과 흐르는 필라멘트 | 다른 픽셀 아트에 비해 부드러운 블러가 강하므로 톤과 시야 방해 확인 필요 |
| 번개 | 여러 굵기의 청록빛 지그재그와 분기 | 밝은 광원이 다수 적 위에 겹칠 때 시야 확인 필요 |
| 근접 기뢰 | 증강 아틀라스 이미지, 외곽 형태를 따른 각진 클리핑 | 원형 테두리를 제거했지만 클리핑은 수동 근사이므로 실제 크기에서 가장자리 확인 필요 |
| 폭격 포드·폭발 | 투하 폭탄과 프레임 기반 주황 폭발 | 실제 폭발 범위 및 시야 가림 확인 필요 |

| 파동·근접 신관·히든 발동 | 얇은 링과 밝은 입자 | 경계가 적 탄환과 겹쳐 혼동되지 않는지 확인 필요 |
| 부메랑 계열 | 단순한 십자형 캔버스 도형 | 다른 이미지형 스킬에 비해 이질감이 클 가능성이 높아 우선 개선 후보 |

## 기능 검증
- 일루전 포함 기뢰는 전체 개수 기준으로 여러 줄의 부채꼴에 분산한다.
- 무장된 기뢰는 적 기체 또는 적 일반 탄환을 감지하면 폭발하고 폭발 범위의 일반 탄환을 제거한다. 레이저는 지속형 공격이므로 제외한다.
- 매우 빠른 탄환은 프레임 사이 이동 경로를 검사해 통과 충돌을 감지한다.

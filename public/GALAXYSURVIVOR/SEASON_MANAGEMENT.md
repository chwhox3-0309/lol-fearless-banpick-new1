# 시즌 정보 관리

`season-config.js`에서 label(시즌 번호), title(이름), period(기간 안내), description(소개), status(상태)를 변경하고 `npm run build`로 새 번들을 만듭니다. 날짜가 정해지지 않은 초기 상태는 준비 중으로 표시합니다. 기간은 표시용 문자열이며 날짜가 지나도 자동 변경되지 않습니다. 앱 업데이트 전 버전을 보는 이용자는 이전 내용을 계속 볼 수 있습니다.

현재 시즌 정보는 화면 표시만 담당합니다. 토스 전체 리더보드는 시즌별로 분리되거나 초기화되지 않으며, 시즌별 점수·보상·집계·서버 저장 기능도 구현되어 있지 않습니다. 실제 시즌제 운영 전 데이터 관리, 시즌 전환, 점수 검증, 순위 집계 및 종료 시점의 처리를 설계하고 검증해야 합니다.
